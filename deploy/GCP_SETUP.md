# Google Cloud（無料枠）で自動運転する手順

所要時間は30〜40分ほどです。PCの電源は切っておけます。実際の投票は一切行いません（仮想記録のみ）。

## 0. 無料で使うための条件（ここを外すと課金されます）
| 項目 | 必ずこの設定にする |
|---|---|
| リージョン | `us-west1`（オレゴン）、`us-central1`（アイオワ）、`us-east1`（サウスカロライナ）のいずれか |
| マシンタイプ | `e2-micro` |
| ディスク | **標準永続ディスク**（「バランス」ではない）、30GB以下 |
| 台数 | 1台だけ |

- 外部IPアドレスの料金の扱いは変わることがあります。下の手順2で必ず**予算アラート**を設定し、翌日に「お支払い」画面で請求額が0円か確認してください。
- 通信量は、データの受信（ダウンロード）が無料です。このプログラムの送信量はごくわずかで、無料の範囲（月1GB）に収まります。

## 1. アカウントとプロジェクト
1. https://console.cloud.google.com を開き、Googleアカウントでログインする
2. 利用規約に同意し、請求先アカウントを作る（クレジットカードの登録が必要。無料枠の範囲なら請求されない）
3. 画面上部のプロジェクト選択から「新しいプロジェクト」を作る（名前の例：`keirin`）

## 2. 予算アラート（念のため）
1. 左メニューの「お支払い」→「予算とアラート」→「予算を作成」
2. 金額を **100円** にして、50%・100%の時点でメールが届くようにする

## 3. サーバー（VM）を作る
1. 左メニューの「Compute Engine」→「VMインスタンス」を開く（初回はAPIの有効化を押して1〜2分待つ）
2. 「インスタンスを作成」を押し、次のとおり設定する
   - 名前：`keirin`
   - リージョン：`us-west1`（ゾーンはどれでもよい）
   - マシンの構成：シリーズ `E2`、マシンタイプ `e2-micro`
   - ブートディスク：「変更」→ OS `Debian`、バージョン `Debian GNU/Linux 12 (bookworm)`、ディスクの種類 **標準永続ディスク**、サイズ `30` GB
   - ほかの項目は初期値のまま
3. 右側に表示される月額見積もりに「無料枠」の表示があることを確認してから「作成」を押す

## 4. ファイルを送って導入する
1. VMの一覧で `keirin` の行にある「**SSH**」を押す（ブラウザで黒い画面が開く）
2. 黒い画面の右上「ファイルをアップロード」から、PCにある次の2つを順に送る
   - `C:\Users\take0\.claude\keirin\deploy\keirin_deploy.tar.gz`（約24MB）
   - `C:\Users\take0\.claude\keirin\deploy\install.sh`
3. 黒い画面に次のコマンドを貼り付けて Enter を押す（5〜10分かかる）
   ```
   bash install.sh
   ```
4. 途中の「5/6 接続確認」の結果を確認する
   - `www.winticket.jp ... -> 200` と「開催一覧の取得テスト: (8, 79)」のように数字が出れば **成功**
   - `403` などが出た場合は、海外からの接続が拒否されています。その表示をClaudeに伝えてください（日本リージョンに切り替える案を出します。その場合は月700円前後かかります）

## 5. PCからの切り替え（重複を防ぐため）
- PC側のループは、その日の最終レースが終わると自動で止まります。サーバーは、翌朝7:30から自動で動きます。
- 切り替える日の朝7:30より前に、PC側の最新データをサーバーへ移すには次のようにします。
  1. PCで `python deploy\build_package.py` を実行してパッケージを作り直す（Claudeに頼んでもよい）
  2. 手順4の2〜3をもう一度行う（上書きされる）
- 以後、PCで `run_day.py` を動かさないでください（記録が二重になります）。
- タスクスケジューラに `KeirinVirtualTest` を登録していた場合は、解除してください。

## 6. 結果を見る
- SSH画面で次を実行すると、進行状況が流れます（`Ctrl+C` で表示を終了。プログラムは止まらない）
  ```
  tail -f ~/keirin/logs/run_daily.log
  ```
- レポートは、SSH画面右上の「ファイルをダウンロード」で `/home/<ユーザー名>/keirin/out/analysis_report.md` を指定すると、PCに保存できます（`history_report.md` は過去分析）
- 自動起動の予定を確認するには:
  ```
  systemctl list-timers keirin.timer
  ```

## 止めたいとき
```
sudo systemctl disable --now keirin.timer
```
VMそのものを削除すれば、料金が発生する可能性は完全になくなります（Compute Engine → VMインスタンス → 削除）。
